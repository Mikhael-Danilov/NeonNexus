Политика конфиденциальности

Браузерная игра «Neon Nexus» (далее — Игра) уважает вашу приватность и соблюдает 152-ФЗ «О персональных данных».

Какие данные обрабатываются

  • Игровые рекорды (таблица результатов и суммарный счёт фрагов) — хранятся только в локальном хранилище вашего браузера (localStorage) и никуда не отправляются.
  • Параметры запуска, которые платформа добавляет к адресу игры (подпись, идентификатор пользователя и т. п.), используются только для служебного подтверждения запуска внутри VK и Игрой не обрабатываются и не сохраняются.
  • Игра не собирает имя, телефон, e-mail, геолокацию, контакты и не передаёт данные третьим лицам.
  • Игра не использует аналитические счётчики, файлы cookie для отслеживания и рекламные модули.

Где хранятся данные

У Игры нет собственного сервера: страница и все ресурсы — статические файлы, весь игровой процесс выполняется в вашем браузере.

Удаление данных

Рекорды удаляются вместе с данными сайта: очистите данные браузера для адреса Игры (или удалите Игру из своих приложений VK, если играете внутри VK).

Изменения

Актуальная версия всегда доступна по этому адресу. Дата последнего обновления: 07.10.2026.
